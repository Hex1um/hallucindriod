# 幻卓 Huandroid

> 一台会现场生成应用的安卓手机 —— 纯前端、零构建的交互演示。

锁屏、桌面、文件夹、应用抽屉、控制中心、三键导航，全部按真实安卓 UI 还原。点开任意应用，内容由大模型实时生成；在应用商店搜一个不存在的应用，它也会当场被"造"出来。浏览器里访问的网页同样由大模型现场设计，每次都不同。

## 本轮更新

- **并行预热 + 数据缓存**：页面空闲时后台串行预热全部应用的大模型数据；点开应用命中缓存即秒开。退出应用会保存视图快照，**再次进入直接恢复，不重新初始化**（浏览器还会恢复上次访问的网页）。
- **刷新统一收进设置**：所有应用右上角的刷新按钮已移除；「设置 → 数据刷新」支持刷新全部或指定应用的数据。
- **浏览器改为搜索首页**：打开即是一个新标签页（大搜索框 + 快捷网站 + 热门推荐），输入任意内容后才生成网页。
- **UI 按主流 App 复刻**：袋鼠外卖（本地生活首页：九宫格分类 + 双列图文瀑布流）、短视频（视频社区双列卡片 + 频道 tab）、消息（社交消息页：订阅号横排 + 会话列表 + 未读红点）。
- **新增应用**：袋鼠外卖、短视频；应用默认精简为 12 个核心应用 + 智能终端。
- **智能终端**：自然语言指令 → 大模型解析意图 → 真正调用系统接口执行（打开应用、开关手电筒/蓝牙/勿扰、拨号、浏览、商店搜索）；本地规则优先秒回，复杂指令交大模型理解。
- **修复布局根因**：iframe 在隐藏状态下加载导致高度为 0，改为先显示再写入文档，并把外壳布局改成 flex + 100vh。

## 历史更新

- **浏览器网页真·AI 生成**：浏览器内导航时通过 `postMessage` 请求大模型生成完整官网内容（品牌名、标语、Hero、特色卡片、数据条），再用精致模板渲染。
- **应用商店真搜索**：搜任意词都保证返回一个以该词命名的 AI 现场生成应用。
- **上拉抽屉**：不再展示「全部应用」列表。
- **规避版权争议**：真实厂商/产品名替换为中性名称。

## 运行

纯静态站点，无需构建：

```bash
python -m http.server 8080
```

打开 <http://localhost:8080> 即可（建议用线上地址体验完整 AI 能力，见文末）。

## 结构

```
index.html        页面结构（状态栏 / 桌面 / 文件夹 / 抽屉 / 控制中心 / 锁屏 / 安装层）
css/style.css     样式（拟真图标、不透明锁屏、三键导航）
js/data.js        应用注册表（SVG 拟真图标）、Dock、文件夹、词库、农历
js/apps.js        应用生成器（一）
js/apps2.js       应用生成器（二）
js/llm.js         LLM 层：多源竞速 + fallback
js/engine.js      现编引擎
js/main.js        主程序
```

## LLM 多源策略

`js/llm.js` 采用"竞速 + 逐级 fallback"，优先使用真·大模型，而非随机词库：

1. **自定义端点**：设置里填 OpenAI 兼容 API（最稳）。
2. **Pollinations**（`text.pollinations.ai`，免 Key，CORS `*`）：`openai-fast` 与 `openai` 双模型竞速，快的胜出、慢的自动取消。
3. **备用源**：Pollinations 文本端点 + **AI Horde**（众包 GPU 网络，免 Key，CORS `*`）。
4. 全部失败才回退本地词库，状态栏会显示"离线模式"，不伪装成 AI 生成。

> 注：Pollinations 对生产域名 `hex1um.github.io` 直接 CORS 放行；对 `localhost` 等未登记来源会要求 Turnstile 验证，此时自动切到 AI Horde。因此**线上体验最佳**。

可在「设置」里调 `置信度`（0 = 天马行空，1 = 贴近现实）与自定义 API。
