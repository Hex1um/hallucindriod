# Hallucindriod · 幻卓

> 一台会现场生成应用的安卓手机 —— 纯前端、零构建的交互演示。

锁屏、桌面、文件夹、应用抽屉、控制中心、三键导航，全部按真实安卓 UI 还原。点开任意应用，内容由大模型实时生成；在应用商店搜一个不存在的应用，它也会当场被"造"出来。浏览器里访问的网页同样由大模型现场设计，每次都不同。

## 本轮更新

- **浏览器重做（参考 VibeOS 的自研渲染思路）**：区分「网址」和「搜索词」——输入网址进网站页，输入关键词进**搜索结果页**（标题/域名/摘要三行结构，结果可点进对应网页）。网站页按类型渲染不同布局：**社交**（信息流帖子）、**视频**（双列卡片）、**购物**（分类+商品网格）、**资讯**（文章列表）、**官网**（默认）。另加顶部加载进度条，以及生成失败时的「无法访问此网站 / ERR_EMPTY_RESPONSE / 重新加载」错误页。
- **关联预取（重点）**：打开一个应用时，立刻并行向大模型请求「接下来最可能打开」的应用数据（如外卖 → 短视频/消息/音乐，短视频 → 外卖/音乐），切过去时通常已命中缓存直接秒开。预取走两两并发队列、自动去重，且不会抢当前页面的请求。
- **品牌改名**：Huandroid → **Hallucindriod**（Hallucination + Android），更贴合"AI 幻觉"。仓库同步更名为 `Hex1um/hallucindriod`，站点迁至 **https://hex1um.github.io/hallucindriod/**（旧 Pages 地址失效；好友数据做了 key 迁移，不会丢）。
- **桌面可左右滑动**：改为双屏横向分页（scroll-snap + 手势），第二屏放 **BORDER OPS**，点击直接加载线上站点，不经过大模型。
- **图标校正**：所有图标按实际包围盒自动光学居中，修正视觉重心偏移；「短信」换新图标并改名；「智能终端」换成命令行窗口图标。
- **音乐支持搜索**：输入歌名/歌手，即时生成对应歌单并切到第一首。
- **相册改为真实照片**：接入真实图片（加载失败自动降级为占位），支持点击查看大图。
- **外卖所有按钮可用**：九宫格分类、点评榜单、免费试、双列图文笔记、底部五个 tab、搜索都有真实跳转与内容。
- **短视频改抖音风格**：全屏单列上下滑、右侧操作栏、评论面板、五个底部 tab。
- **消息改 QQ 风格 + 好友系统**：注册用户名后加好友，真人走 WebRTC P2P，不存在则由大模型生成专属聊天对象。
- **P2P 联机**：公共 PeerJS 信令 + STUN，用户名哈希作固定 Peer ID；信令不可用自动降级。

## 历史更新

- **并行预热 + 数据缓存**：后台串行预热应用数据，命中缓存秒开；退出应用保存视图快照，再次进入直接恢复。
- **刷新统一收进设置**：应用右上角刷新按钮移除；「设置 → 数据刷新」可刷新全部或指定应用。
- **UI 按主流 App 复刻**：袋鼠外卖（九宫格分类 + 双列图文瀑布流）、短视频、消息。
- **新增应用**：袋鼠外卖、短视频、智能终端（自然语言指令 → 真正调用系统接口执行）。
- **修复布局根因**：iframe 先显示再写入文档，外壳改为 flex + 100vh。

## 运行

纯静态站点，无需构建：

```bash
python -m http.server 8080
```

打开 <http://localhost:8080> 即可（建议用线上地址体验完整 AI 能力，见文末）。

## 结构

```
index.html        页面结构（状态栏 / 桌面 / 文件夹 / 抽屉 / 控制中心 / 锁屏 / 安装层）
css/style.css     样式（拟真图标、不透明锁屏、三键导航）
js/data.js        应用注册表（SVG 拟真图标）、Dock、文件夹、词库、农历
js/apps.js        应用生成器（一）
js/apps2.js       应用生成器（二）
js/llm.js         LLM 层：多源竞速 + fallback
js/engine.js      现编引擎
js/main.js        主程序
```

## LLM 多源策略

`js/llm.js` 采用"竞速 + 逐级 fallback"，优先使用真·大模型，而非随机词库：

1. **自定义端点**：设置里填 OpenAI 兼容 API（最稳）。
2. **Pollinations**（`text.pollinations.ai`，免 Key，CORS `*`）：`openai-fast` 与 `openai` 双模型竞速，快的胜出、慢的自动取消。
3. **备用源**：Pollinations 文本端点 + **AI Horde**（众包 GPU 网络，免 Key，CORS `*`）。
4. 全部失败才回退本地词库，状态栏会显示"离线模式"，不伪装成 AI 生成。

> 注：Pollinations 对生产域名 `hex1um.github.io` 直接 CORS 放行；对 `localhost` 等未登记来源会要求 Turnstile 验证，此时自动切到 AI Horde。因此**线上体验最佳**。

可在「设置」里调 `置信度`（0 = 天马行空，1 = 贴近现实）与自定义 API。
